# AkakGram Build: сборка Telegram.exe одним запуском

Помощник для Windows 10/11 x64. Показывает, что и сколько займёт, спрашивает,
какой exe собрать, и выполняет все шаги сам.

## Как запустить

1. Скачайте папку `tools/akakgram-build` (или только `AkakGram-Build.bat`:
   недостающий `build.ps1` он скачает сам).
2. Запустите `AkakGram-Build.bat` двойным щелчком.
3. Выберите вариант, проверьте план и подтвердите.

## Что делает

1. Проверяет память, диск и процессор и сравнивает их с тем, что нужно.
2. Проверяет Git, Python, CMake (3.25 и новее), Visual Studio с C++, Windows SDK.
   Git, Python и CMake может поставить сам через winget.
3. Показывает план с примерным временем и местом на диске по каждому шагу.
4. Скачивает код вместе с подмодулями, собирает библиотеки, настраивает проект
   и компилирует `Telegram.exe`.
5. Показывает итог и предлагает скопировать exe на рабочий стол.

## Что нужно вручную

Visual Studio 2026 Community с компонентами «Разработка классических приложений
на C++», MSVC v14.44 и Windows SDK 10.0.26100.0. Остальное помощник проверит сам.

## Примерные ресурсы

| Вариант | Диск | Память (пик) | Время |
|---|---|---|---|
| Debug x64 | 40–50 ГБ | 8–12 ГБ | 1,5–4 часа в первый раз |
| Release x64 | 50–60 ГБ | 8–12 ГБ | дольше, чем Debug |
| Только проект | 6–12 ГБ | 8–12 ГБ | 20–60 минут |

Цифры ориентировочные, на вашем компьютере могут отличаться.

## Если что-то пошло не так

Журнал лежит в папке сборки: `akakgram-build-ДАТА.log`. Пришлите последние
30–50 строк. Повторный запуск продолжит с места остановки.
